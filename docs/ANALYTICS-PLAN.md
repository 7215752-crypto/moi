# План отчётов аналитики MOI Group

Утверждается владельцем по кускам, статусы обновлять здесь.
Навигация по отчётам: `components/analytics-nav.tsx` (новый отчёт = новая страница
в `app/analytics/<slug>/` + строка в навигации + строка здесь).
Правило: каждый отчёт, которому нужны продажи из iiko, включает кнопку
`AnalyticsRefreshButton` со своим периодом — данные обновляются на месте,
без похода в другой раздел (решение владельца 06.08).
Последнее обновление: 06.08.2026.
