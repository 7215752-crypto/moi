# Redman Salary Portal

Первая read-only версия портала расчёта зарплаты сотрудников ресторанов Redman.

## Что уже есть

- вход по email и паролю через Supabase Auth;
- серверная сессия в cookies через `@supabase/ssr`;
- защита страниц и чтение данных через RLS;
- список расчётных периодов;
- итоговая зарплата по ресторанам и сотрудникам;
- подробный расчётный листок: часы, оклад, мотивация iiko, сервисный сбор, покупки, KPI и корректировки;
- адаптивный интерфейс для компьютера и телефона;
- только просмотр — портал не меняет базу.

## Требования

- Node.js 20.9 или новее;
- созданный проект Supabase;
- таблицы, функции, view и RLS-политики из текущей настройки проекта;
- пользователь в `Authentication → Users` и связанный профиль `user_profiles` с ролью `owner`.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000` и войдите email/паролем пользователя портала.

Файл `.env.local` уже содержит подключение к проекту Redman Salary и исключён из Git через `.gitignore`.

1. Создайте пустой репозиторий на GitHub.
2. Загрузите содержимое этой папки в репозиторий.
3. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
4. В разделе **Environment Variables** добавьте:

```env
NEXT_PUBLIC_SUPABASE_URL=https://qxskwitgffjtudnaxczv.supabase.co
NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_r0lh-xxyOaweuUz1m6nCUQ_oH4mF3r3
```

5. Нажмите **Deploy**.
6. В Supabase откройте **Authentication → URL Configuration** и укажите адрес Vercel-проекта как Site URL. Добавьте этот же адрес в Redirect URLs.

## Безопасность

В проекте используется только Publishable key. Не добавляйте в код или Vercel:

- `service_role`;
- Secret key;
- пароль базы;
- строку прямого подключения PostgreSQL.

Publishable key не даёт доступ к зарплатам сам по себе: доступ определяется авторизацией пользователя, PostgreSQL grants и RLS-политиками.

## Основные маршруты

- `/login` — вход;
- `/dashboard` — расчётные периоды;
- `/payroll/[periodId]` — зарплата за период;
- `/payroll/[periodId]/employee/[employeeId]` — подробный расчёт сотрудника.
